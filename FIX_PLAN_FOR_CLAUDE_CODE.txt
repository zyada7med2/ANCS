FIX 1 — C5: Huawei prompt regex matches [Y/N] (ROOT CAUSE — FIX FIRST)
================================================================================

FILE: network_manager/vendors/huawei_vrp.py
LINE: 33

FIND THIS EXACT LINE:
            prompt_pattern_exec=r"[<>\]]\s*$",

REPLACE WITH:
            prompt_pattern_exec=r"(?:^|\n)\s*[\[<]\S+[\]>]\s*$",

WHY: The old regex matches any line ending with < > or ]. Huawei's save
confirmation "Are you sure to continue?[Y/N]" ends with ] so it falsely
matches as a device prompt. The new regex requires the bracket to contain
at least one non-whitespace character (a hostname), matching patterns like
<Router> or [Router] but NOT [Y/N] in a question sentence.
