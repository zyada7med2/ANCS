# Contributing to ANCS

Thank you for your interest in contributing to the Auto Network Configuration System (ANCS)!

## How to Contribute

1. **Report Bugs**: Use GitHub Issues to report bugs with reproducible steps.
2. **Propose Features**: Open an issue describing the feature and its use case.
3. **Submit Pull Requests**:
   - Fork the repository.
   - Create a feature branch (`git checkout -b feature/amazing-feature`).
   - Write clean code adhering to Python PEP 8 standards.
   - Run existing tests inside `network_manager/tests/` to ensure no regressions.
   - Commit changes with clear, descriptive commit messages.
   - Push to your branch and submit a PR to the `main` branch.
